## Lab requirements

The following requirements describe the necessary deliverables for the Intro to Infrastructure as Code Lab.

| Criteria                                                                                                             | Points |
| -------------------------------------------------------------------------------------------------------------------- | ------ |
| The Terraform configuration file includes an EC2 instance to host a web application with the correct specifications. | 50     |
| The Terraform configuration file includes a security group to control inbound traffic to the virtual machine.        | 10     |
| The Terraform configuration file's security group permits inbound HTTP traffic from anywhere.                        | 10     |
| The Terraform configuration file includes an elastic IP address associated with the virtual machine.                 | 10     |
| The Terraform configuration file is formatted with a consistent indentation and style.                               | 10     |
| The Terraform configuration file has the correct syntax and structure.                                               | 10     |
| **Total possible points**                                                                                            | 100    |
