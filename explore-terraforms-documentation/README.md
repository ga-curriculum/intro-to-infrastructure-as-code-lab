## Exploring the Terraform Documentation

In this exercise, you'll explore the Terraform documentation to find information about the resources and configurations used in the next exercise.

1. **Access the Terraform Documentation**

   Open a web browser and navigate to the official [Terraform documentation website](https://www.terraform.io/docs/).

   Familiarize yourself with the structure and organization of the documentation.

2. **Find Resource Documentation**

   In the Terraform documentation, locate the AWS provider documentation.
   Find the documentation for the following resources you will be using:

   - aws_instance
   - aws_security_group
   - aws_eip

   Read through the resource documentation to understand their purpose, available arguments, and usage examples.

3. **Explore Configuration Examples**

   Within the resource documentation, look for configuration examples that demonstrate how to use and configure each resource.

   Identify any additional arguments or configurations that could be relevant to your use case.

4. **Reflect on Documentation Findings**

   Reflect on how the documentation helps in understanding and configuring resources effectively.

   Highlight any interesting or useful examples or configurations you discovered during your exploration.
